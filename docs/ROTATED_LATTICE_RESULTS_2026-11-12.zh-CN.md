# 第一次 3D 晶格旋转实测：A → B → A（2026-11-12）

## 设计

目标是落实用户提出的旋转规则：

- 2D Embedding Matrix 的行永远是整数 index `v`，列永远是滑动窗口位置 `r`。
- Task A 原位置训练；Task B 绕行轴在三维晶格中旋转一次 90°。
- 推理时使用相同任务方向（Task A 的输入读取 A 平面，Task B 读取 B 平面）；不依赖真实二分类标签。
- 使用同一个三维坐标空间中的**可训练共享格点**，而不是把两个无关的模型随意拼在一起。
- 当前仍属于需已知 A/B 任务身份的 **task-wise binary** 实验。

具体空间坐标，窗口 `m=30`，二分类输出槽 `c=0,1`：

A：`(v,r,c*(m+1))`

B（允许自然相交）：`(v,0,c*(m+1)+r)`

B（不共享控制组）：`(v,m,c*(m+1)+r)`

相交版只在 `r=0` 的行轴交线上，向同一类输出槽共享实际的参数。对于不共享的其他格点，B 不会修改 A。独立偏置，B 不更新 A 的偏置。

## 训练设置

- UCI Epileptic Seizure Recognition，原生 178 长度整数序列，原始 5 类。
- Task A = 原始标签 1 vs 5；Task B = 原始标签 2 vs 4，分别映射到两个二分类输出。
- 每任务原始训练 3,680，测试 920；按 EEG segment 划分 80/20，不是 subject-wise 临床划分。
- 每输出槽对应一张整数查表/窗口位置矩阵；窗口 30、滑动窗口逐步长 1。
- A 与 B 各训练 20 epoch，seed 42；学习率 0.005、batch 128；无 replay。
- SparseAdam 仅更新被访问的空间标量，Adam 更新各任务独立 bias（因此优化器与旧固定矩阵基线不同）。
- 学习 B 之前保留 A 的全部词表 ID 和空间权重，未对整数信号做分箱。

## 真实实测

| 方案 | 学完 A 测 A | 学完 B 再测 A | 学完 B 测 B | A 遗忘 |
|---|---:|---:|---:|---:|
| 旧版固定两矩阵继续覆盖（seed 42） | 97.17% | 61.96% | 67.17% | 35.22 pp |
| **90° 旋转、交线共享** | 97.17% | **97.07%** | 65.33% | **0.11 pp** |
| **90° 旋转、不相交** | 97.17% | **97.17%** | 65.54% | **0.00 pp** |

交线共享版，共享的有效三维格点为 **2,978** 个；总活跃空间标量 **282,442**，加 4 个独立 Task-class Bias，共 **282,446** 参数。

完全不相交版，共享有效格点为 **0**，总活跃空间标量 **285,420**，加偏置共 **285,424** 参数。

### A 的混淆矩阵

A 学完：

```
       pred 0   pred 1
true 0    438       22
true 1      4      456
```

交线共享版、学完 B 后：

```
       pred 0   pred 1
true 0    437       23
true 1      4      456
```

不相交版学完 B 后，A 的混淆矩阵保持**完全不变**。

## 科学解释与局限

1. 90° 旋转实现了保存任务 A 时不破坏其余大部分参数的**空间分配**。这是一个有效的存储/寻址结构验证，不代表解决了 Lifelong Learning 的完整问题。
2. 完全隔离 A 的 0% 遗忘是机制的直接结果；与保存不同任务权重类似。这里不声称新颖的非遗忘机制。
3. 允许自然交线共享时，B 的学习改写了 A 的少量权重，只引起 A 准确率下降 0.11 pp（920 个 A 测试样本中多错 1 个）。
4. **B 在共享版 65.33%，隔离版 65.54%，共享并未提高 B 的准确率。** 本轮不能证明有效的知识迁移或可复用特征学习。
5. 原始共享表对照使用 Adam，新的稀疏空间实现使用 SparseAdam，加上独立偏置和更大参数容量，暂不应把性能差异归因于“旋转本身的优越性”。
6. 已知任务方向用于推理；若不给 Task A/B 标签，尚需设计自主寻址 / 统一评分机制。
7. 离散整数晶格中绕行轴反复 90° 旋转只有有限个轴对齐方向，不支持无限独立表面；增加新任务需要进一步定义平移或别的空间组织方法。

## 推荐后续实验

第一步不急于创造复杂旋转角度。保留这个保守模型，优先测试同一组参数和优化器下，**平行隔离 / 垂直隔离 / 垂直共享交线** 的差别，并通过 A、B 双任务预测，检查是否真的产生了正向迁移。
