# PenDigits：A+B 混合训练的两种模型各自四分类 Baseline（2026-11-12）

## 比较问题

用户要求：不是只比较 A 后 B 的增量测试，而是**让 A=(0,1) 与 B=(2,3) 的样本一起进入训练，从一开始同时学习四类别，再对 A+B 混合 TEST 做全局四分类**。

同样的数据：
- UCI PenDigits 原始整数 16 维有序笔迹，官方作者分离 TRAIN/TEST。
- A+B 总训练样本 **3058**，四类 TEST **1427**。
- 所有四类标签均在训练起点可见；推理不提供 task ID。

模型：
1. **CE 联合训练基线**：原 2D index–position `W_c[101,16]` 结构，4-way Softmax Cross-Entropy，Adam lr .01、30 epochs。来自此前已实测 `results/pendigits_joint_seed42/metrics.json`。
2. **One M 45° 旋转联合训练**：只有同一个 `M[v,y,z]`，中心旋转轴预留空列，四个方向为 0°、45°、90°、135°。将 4 类 TRAIN 样本混合随机打乱，**在同一次训练遍历中直接更新同一个 M** 中对应类别方向的整数–位置统计，没有先构造四张独立矩阵。按方向对数似然得分做全局四分类。来自本次新实际运行。

学习目标不同。下面是用户要求的**各自 joint 4-class 基线**，不是将它们宣称为严格单变量几何因果对照。

## 实验结果

| 指标 | CE 四类混合联合训练 | 单 M 旋转四类混合联合训练 |
|---|---:|---:|
| TEST 四分类整体准确率 | **92.01%** | **85.91%** |
| A=(0,1) 预测准确率（在全部四类分数中竞争） | **88.58%** | **76.07%** |
| B=(2,3) 预测准确率（在全部四类分数中竞争） | 95.57% | **96.14%** |
| Class 0 | 94.77% | 92.56% |
| Class 1 | **82.42%** | 59.62% |
| Class 2 | 93.96% | **95.05%** |
| Class 3 | 97.32% | 97.32% |

CE joint 胜出 **6.10 个百分点**。单 M 的主要弱项是 Class 1，其 accuracy 从 CE 的 82.42% 降至 59.62%。B=(2,3) 反而是单 M 略高（0.57 pp）。

混合训练对照与真正增量对照对齐：

| 模型 | A+B joint training，最后 4-way | A→B sequential，最后 4-way |
|---|---:|---:|
| CE 判别式 | **92.01%** | **54.59%** |
| 单 M 正样本计数学习 | **85.91%** | **85.91%** |

单 M 的 joint 和 incremental **完全一致**（测试样本级预测与完整混淆矩阵严格相同）：因为新类别的整数–位置计数是加法累积的、不同角度互不重叠；训练顺序不影响最终 M 的统计内容。该结论对于当前频率学习规则成立，并不表示其他优化规则也有此性质。

CE joint 不出现这种增量阶段的遗忘，因为从训练开始就有 A+B 四类别共同参与损失；但先 A 后 B 训练时在全局 CE 下旧类得分受到改变，四类测试仅 54.59%。

## 解释与下一步

- 两者在单独完成 A 或 B 时的高准确率，不能说明同时四分类也一样好；四类共同竞争时 Class 1 与 Class 2 混淆是重要差异。
- **新模型擅长保持已经学到的类别权重，不代表它已经达到最高的四分类判别能力。**
- 当前单 M 的“保持旧权重”优势来自各方向不重叠与类别独立的计数目标；几何旋转不提高比同目标独立二维表的准确率。
- 接下来若要检验最初 IoT 学习方法的旋转结构，应使用**同一个可比较的 Cross-Entropy 或一致的判别损失**，给单 M 方向学习提供可比优化过程，再比较四类 joint、增量 A→B、总体精度和参数开销。
