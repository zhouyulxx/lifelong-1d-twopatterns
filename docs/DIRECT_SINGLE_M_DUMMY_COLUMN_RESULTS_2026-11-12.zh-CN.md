# 直接在唯一 3D M 上学习：旋转轴空白列实验（2026-11-12）

## 用户原始结构的严格实现

- 模型只有一个真正储存知识的 3D 数组 `M[v,y,z]`，从头固定分配 `shape=(101,33,17)`，其中 `v` 是原生整数取值 0..100。
- Class 0,1,2,3 在同一个 M 中依次使用方向 0°、45°、90°、135°，沿 Row 整数索引轴旋转。
- **几何第 0 列（旋转轴）完全空白**，实际输入位置 `r=0..15` 映射为距离旋转轴 `r+1=1..16`。
- 训练时读取本类别样本，在 **M 的指定方向坐标上直接累加整数计数**；没有先计算/持有独立类别矩阵，学习期间也没有复制旧矩阵权重。
- 推理时不知道类别或 Task ID：遍历 M 中已学习的全部方向，计算统一分数并比较。
- 唯一额外的类别相关元数据是方向映射和各类别训练样本数；没有独立的可训练 W_c。

## 精确坐标映射

```
Class 0: (v, 16 + (r+1), 0)
Class 1: (v, 16 + (r+1), r+1)
Class 2: (v, 16,         r+1)
Class 3: (v, 16 - (r+1), r+1)
```

不同类别之间不共享任何有效格点。每学新类别后，程序逐项检验所有旧方向上的 M 值**完全一致**，并检查旋转轴 `M[:,16,0]` 仍全零。

注意：这是同一 3D 数据结构，但不同方向读写不同地址，几何旋转本身不复制矩阵，也没有额外的旋转训练参数。

## 学习目标

单类别正样本对应的值–位置计数直接储存于 M：

\[
N_c(v,r) = M[\Phi_c(v,r)]
\]

从本类别的总训练样本数 \(n_c\) 和平滑系数 \(\alpha=1\) 计算每位置条件对数概率：

\[
S_c(X)=\sum_{r=0}^{15}
\log\frac{N_c(x_r,r)+1}{n_c+101}
\]

并选择 \(\arg\max_c S_c(X)\)。

这是单类别正样本的经验分布学习，不是原始论文中的 Adam/CE 判别式优化；`M` 当前储存的是整数统计值，类别对数权重在推理时从 `M` 计算。

## 成功完成的实际实验

UCI PenDigits 官方 TRAIN/TEST，原生 16 整数序列，按数字 `0→1→2→3` 依次逐类学习。

| 学完类别 | 所有已见类别统一推理准确率 |
|---|---:|
| 0 | 无意义，未报告 |
| 0,1 | **96.70%** |
| 0,1,2 | **84.05%** |
| 0,1,2,3 | **85.91%** |

- 学完 0、1 时，Task A 准确率 **96.70%**。
- 学完 2、3 后，同一完整 4-class 模型中，Task A 准确率 **76.07%**，Task B 准确率 **96.14%**。
- 最终全局四分类 **85.91%**。
- 所有阶段的总准确率、逐类准确率和完整混淆矩阵与此前同目标的独立类别表**逐项完全一致**，由 GitHub Actions 自动断言。
- 所有旧类对应 M 格点在后续学习阶段都被严格验证未改变。
- **一共只有一个 M**，有效权重坐标 **6464**，无共享冲突。
- 这个实现为方便检测使用预分配密集 `101×33×17=56661` 个 int32 格点；空间预分配是现实的内存成本，即使旋转坐标计算不需要复制权重。稀疏化可以减少空白格点的内存分配，但不改变实验结果。

## 正确的 Baseline 比较

另一套原先判别式 Cross-Entropy 的 Class-Incremental 学习在同样 A=(0,1) / B=(2,3) 顺序下，Seed42 实测：

| 结果 | CE 判别式 Baseline | 单 M 方向增量 + 单类频数学习 |
|---|---:|---:|
| 学完 A 测 A | 97.25% | 96.70% |
| 学完 B 测 A | 11.28% | 76.07% |
| 学完 B 测 B | 99.57% | 96.14% |
| 最终四分类 | 54.59% | 85.91% |

二者的训练损失不同，因此 31.32 pp 的准确率差**不能直接归因于几何旋转**。单 M 与“普通独立表存储”的同目标对照结果完全相同，因此这轮严格证明的是**单晶格直接学习的空间索引正确、旧参数保留及无需 Task ID 推理**，不是旋转带来新的统计学习能力。
