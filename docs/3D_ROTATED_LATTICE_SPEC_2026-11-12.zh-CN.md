# 3D 晶格旋转实验：语义不变的 Row / Column 轴（2026-11-12）

## 用户设计意图

把每个输出类别的 **Index–Position 2D Table** 放入一个空间三维晶格，并且：

1. Table 的 Row 永远是 integer vocabulary index \(v\)；Column 永远是窗口内的 position \(r\)，两者不能交换意义。
2. 首先学习 Task A：使用原始方向。
3. 其次学习 Task B：绕 Row 轴旋转一次，\(90^{\\circ}\)，不重置已学的 A 权重。
4. 测试 A 使用 A 的原方向；测试 B 使用 B 的旋转方向。
5. 记录 Task / Class / rotation history / vocabulary mapping，以防忘记哪个矩阵在哪个平面。

## 具体晶格

这次 EEG 基线使用一个任务中的两个输出类别位置 \(c=0,1\)，每类一张 \(|V|\\times m\) 的 Index–Position Table。

在一个三维格点空间 \(M(v,y,z)\) 中定义每类平面：

- Task A：\(\\phi_A(c,v,r)=(v,r,c(m+1))\)
- Task B：\(\\phi_B(c,v,r)=(v,0,c(m+1)+r)\)

此处第三个轴并非“时间”，而是真正的几何空间轴。

**A → B 是一个 90 度旋转，而不是转置矩阵**：固定行索引方向 \(v\)，让位置方向从 \(y\) 旋到 \(z\)。

两者在 \(r=0\) 时自然相交：\(\\phi_A(c,v,0)=\\phi_B(c,v,0)\)。

这意味着同一个整数索引 \(v\) 在不同任务、相同输出槽位 \(c\) 的首个窗口位置共享相同的**实际可训练参数**。这是一种特定、非常稀疏的共享规则，不是自动学得的最优知识共享。

## 对照组：旋转后再平移

独立对照把 B 平面平移到：

\(\\phi_B^{independent}(c,v,r)=(v,m,c(m+1)+r)\)

于是 A/B 不再共享任何格点。A 旧权重及其 Bias 均不受 B 梯度改变。

对照组能定量证明：**完全隔离可以消除参数覆盖，但不能因此推断发生了知识共享或知识迁移。**

## 实现细节

- 使用 sparse spatial coordinate map，把三维坐标 \((v,y,z)\) 唯一映射到可训练标量。仅为实际使用的格点分配权重，不把所有空白格点也存入参数。
- 即使参数在内存中压缩成一个一维表，这仍然是有明确三维坐标的晶格；重叠格点使用相同的参数 ID。
- 学 B 时只给 B 的整数值新增词表行，保持 A 原索引顺序，已有的空间坐标权重原封不动复制。
- A/B 均使用两输出、窗口长度 30、各 20 epoch、Adam 类优化器与同样的原生整数 EEG 数据。
- 由于使用 sparse coordinate storage，优化器为 SparseAdam（查表权重）以及 Adam（独立任务 Bias），与旧基线中单纯 Adam 的优化路径不完全相同。因此后续强结论需要做同优化器控制实验。
- 两个任务独立 Bias；B 的训练只能通过**实际共享的晶格格点**修改 A 的学习。
- 推理已知任务方向，但不使用每条样本的真实类别来决定方向；这不等价于 Task-ID 未知的通用增量分类。

## 重要数学限制

三维实数空间有无限多种二维平面朝向；但在需要**保持所有整数晶格点精确对齐**、并仅使用 \(90^\\circ\) 旋转的这个设计中，单纯绕 Row 轴旋转并不能生成无限个独立方向。

以后如要存更多任务，需要引入 **平移 / 多层 / 合法整数角度变换 / 稀疏空间索引** 等方式；不能声称每个新任务无限次旋转都不会重叠。

## 最简可复现方式

\`\`\`bash
python run_rotated_3d_lattice.py --mode intersection --seed 42
python run_rotated_3d_lattice.py --mode isolated --seed 42
\`\`\`

比较 \(Acc(A|A)\)、\(Acc(A|A,B)\)、\(Acc(B|A,B)\)、空间共享格点数量与参数数目。
