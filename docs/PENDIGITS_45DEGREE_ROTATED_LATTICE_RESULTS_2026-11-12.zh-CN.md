# 45° 三维旋转晶格：原生整数 PenDigits 四类别实测（2026-11-12）

## 目的与固定模型

用户提议：每新学习一个 Class，把每类的二维整数索引–序列位置 Embedding Matrix 绕 Row（整数索引）轴旋转一次；四个 Class 使用角度 **0°、45°、90°、135°**。先看实际结果，不预设复杂扩展规则。

数据：UCI PenDigits，官方原生 TRAIN/TEST，输入 16 个整数、10 类。本次只学习数字 0、1、2、3，**每一阶段只拿新类别训练样本**；预测时使用所有已学类别的全局 argmax，不传 Task ID。

学习器：每类一张 `101×16` 的 Index–Position **平滑对数频率表**（Dirichlet alpha=1），只有该类的正样本就可以学习。它是由原论文 Index–Position 查表机制改造出的生成式训练目标，**不是论文原始的判别式 Softmax CE 模型**。

第一阶段只有一个已见类别时，不报告没有意义的单类别 closed-set accuracy；从第二阶段开始报告准确率。

## 空间旋转

三维晶格的坐标是 `(v,y,z)`，其中 `v` 恒为整数词表 ID，`r` 恒为位置。将 Class `c` 的位置轴映射到整数格点方向：

| Class | 角度 | 方向向量 `(dy,dz)` | 空间坐标 |
|---|---:|---|---|
| 0 | 0° | (1,0) | (v,r,0) |
| 1 | 45° | (1,1) | (v,r,r) |
| 2 | 90° | (0,1) | (v,0,r) |
| 3 | 135° | (-1,1) | (v,-r,r) |

只有位置 `r=0` 的一条 Row 轴在四张矩阵之间重叠，其他位置各自独立。新增类别写入共享轴的实际坐标会覆盖先前类别在那里存储的值。每次预测**从同一物理坐标储存字典读取矩阵**，因此共享不是只在可视化里的重叠。

完全隔离对照：角度仍是 0°、45°、90°、135°，但是每类平面添加不同原点偏移，所以不会共享任何格点。

## 实测结果

| 已学类 | 共享交线 `shared_axis` | 完全隔离 `isolated` |
|---|---:|---:|
| 0、1 | 96.56% | 96.70% |
| 0、1、2 | 83.96% | 84.05% |
| 0、1、2、3 | **85.07%** | **85.91%** |

四分类时：共享交线版 `0.8507358093903293`，完全隔离版 `0.8591450595655221`，相差 **−0.841 个百分点**。

### 四类时逐类准确率

| 原始标签 | 共享交线 | 完全隔离 |
|---|---:|---:|
| 0 | 92.29% | 92.56% |
| 1 | 56.04% | 59.62% |
| 2 | 95.33% | 95.05% |
| 3 | 97.62% | 97.32% |

因为类别 1 的结果比较低，四分类总准确率并非所有类别均高于 90%。

### 参数存储成本

- 四张独立完整表共 `4 × 101 × 16 = 6464` 个标量。
- 共享交线共合并 `3 × 101 = 303` 个重复空间格点，总占 `6161` 个标量。
- 共享版较独立版节省 `303/6464 ≈ 4.69%` 的权重存储。
- 这里没有计入字典映射 / 几何坐标的实现元数据开销，不能当成整个程序内存节省 4.69%。

## 科学解释（需要避免过度结论）

1. **这种 45° 旋转加共享交线并没有改善准确率**：四分类低 0.84 pp。
2. 不相交旋转与普通独立矩阵**严格等价**。实验脚本在计算中逐值对照，断言结果与先前原生独立矩阵实验的四分类结果一致。
3. 共享版只在 r=0 覆盖：四类训练完成后，它们读取到的第 0 个位置权重完全相同。因此，这部分在不同类别分数相减时抵消，**相当于丧失 r=0 的类别判别信息**；它不是有效正向知识迁移的证据。
4. 用这个实验不能证明旋转能解决 Class-Incremental Learning 的所有问题。因为当前是生成式逐类统计更新、旧类权重大部分冻结，它与之前的 CE 判别式 baseline （A→B→A 旧类 97.25%→11.28%）学习目标不同，不是同目标的公平算法优劣比较。
5. 这次是真正有四种不同方向的 3D 晶格空间；整数格点上的 45° 使用原始方向向量 (1,1)，不是单位长度插值或浮点网格旋转。

### 下一步

不再纠缠旋转角度。若要提升效果，应考虑有选择性的共享规则，不应强制把每个类别的 `r=0` 权重全部设成同一个值。需要同学习目标下的 A/B 性能、逐类错误、存储量对照，才能判断这种共享是否有收益。
